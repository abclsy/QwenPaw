## 第五轮修复（16:29 footer 消失+列表不滚）

根因：**antd Sider 会把所有 children 包进内层 `.qwenpaw-layout-sider-children` div**，上一轮把 flex column 加在外层 aside 上没生效——内容总高超出 100vh 被 aside 的 overflow:hidden 裁掉（footer 挤没、historyList 高度 auto 不滚）。
正确做法：`:global(.qwenpaw-layout-sider-children) { display:flex; flex-direction:column; height:100%; min-height:0; }`（嵌套在 .sider 里），层级：children → siderScrollContent(flex:1) → navList(flex:none) + 历史区(flex:1 内滚) → siderFooter(flex:none static) 沉底。改 antd Sider 内部布局必须打这个内层类（项目 prefix 是 qwenpaw）。
