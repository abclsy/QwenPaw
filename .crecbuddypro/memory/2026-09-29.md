## 三模式 D1 后端完成（10:35）

- **关键架构发现**：AgentRequest（agentscope_runtime）是 `extra="allow"`——前端 query 请求体直接带 `mode` 字段即可透传到 runner，**无需改任何 schema**。
- 实现（commit 已提交）：
  - react_agent.py：`__init__` 加 `mode` 参数（ask/plan/craft，未知值回退 craft）。ask → `init_kwargs["toolkit"]=None + max_iters=1`（不进 ReAct 循环）+ 跳过 memory 工具注册；`_acting` 加 ask 硬门控（模型仍输出工具调用时拒绝并提示切换模式，防注入）；`register_mcp_clients` ask 模式下 no-op（toolkit 为 None 会崩，必须跳过）
  - runner.py：从 `getattr(request, "mode", "craft")` 提取（模式与 root_session_id 提取同款）；`work_mode=="plan"` 时强制 `plan_enabled=True`（会话级模式优先于 agent 级开关）+ 传 `mode=work_mode` 给 QwenPawAgent
  - tests/unit/agents/test_work_modes.py：5 个单测全绿（AgentProfileConfig 必须带 name 字段，踩过坑；本机跑 pytest 需 `pip install --break-system-packages pytest pytest-asyncio`）
- 后端全链路：前端带 mode → runner 提取 → agent 装配。D2 开始前端三态切换器。
