## 产物通知 mac 不生效修复（10:50）

用户 mac 实测通知不弹。探针脚本证实：**WKWebView 里 Notification.permission 硬死在 denied，requestPermission 永远 denied**——WebKit 只在 Safari 给网页通知授权，嵌入式 webview 一律拒绝（WebView2/Windows 才支持）。我最初"双端都支持 Web API"的假设错了。

修复（双路由）：desktop_cmd 加 `show_notification` 原生桥（mac 用 osascript display notification，已实测可弹；Windows 兜底 PowerShell NotifyIcon）；前端 Web API 未授权时自动落原生桥（mac 无点击直达——osascript 无回调，点击直达仍是 WebView2 专属）；设置页识别原生路由后不再显示误导性的"权限被拒"警告。

⚠️ 平台知识沉淀：**跨平台 webview 能力差异要先探针验证再写代码**——WKWebView：网页通知✗、其他（如 clipboard 部分 API）也要留意；WebView2（Chromium 内）接近 Chrome 全量。
