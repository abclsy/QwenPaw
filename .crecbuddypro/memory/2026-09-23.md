### Windows CI 失败根因与修复（16:23）

- **根因**：`conda run` 会缓存子进程全部输出、最后用 Python print() 回放（conda/cli/main_run.py:141）。Windows Python stdout 默认 cp1252，构建日志含中文（专家模板、中文文件名 启动CrecPaw.command 等）→ 回放时 UnicodeEncodeError 崩溃。构建本体 23 分钟基本跑完，是收尾打印挂的。macOS job 正常是因为 macOS Python 默认 UTF-8。上游构建时好时坏同理（输出内容碰巧含非 cp1252 字符就挂）。
- **修复**：desktop-release.yml 的 Build Windows installer 步骤加 env：`PYTHONIOENCODING: utf-8` + `PYTHONUTF8: "1"`（commit 8fb40d70），待用户推送 fork 后重跑。
- GitHub API 匿名拿不到 job 日志（需 admin 权限），check-runs/{id}/annotations 接口可匿名拿但只有摘要——下次让用户直接从网页复制报错更快。
