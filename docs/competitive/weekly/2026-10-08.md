## 二、本周更新内容摘要

### 1. v5.7.0（9/28）—— 重大功能版本 ⚠️

9 项新功能：

- **定时任务页面焕新**：集中查看任务模板、配置与运行记录，任务失败时更容易定位原因。
- **全局搜索**：可查找资料库内容和聊天记录。
- **工作区信任确认**：首次打开含开发配置的工作区时保护本地文件与运行环境。
- 桌面任务通知授权引导（电脑和关联移动端均可收到提醒）。
- 插件查看与卸载、技能搜索与安装（对话内完成）。
- 右侧面板新标签页直接查看和打开对话产物。
- 本地 Markdown 查找替换；Markdown/HTML 预览缩放；HTML 产物页面内查找。
- 支持从 WorkBuddy 在 **CodeBuddy** 中打开工作空间（与 IDE 打通）。
- 开发者可分享已公开发布的专家、应用、技能等资产（分享链接直达详情页）。

另含多项优化（对话前技能推荐、专家/技能页展示开发者信息、启动与会话切换等待体验）及大量稳定性修复（新任务无回复、历史会话恢复卡住、Windows 本地模型加载超时、HTML 产物预览白屏等）。

### 2. v5.7.2（9/29）/ v5.7.3（9/30）—— 稳定性版本

- 5.7.2 修复：企业下发的助理在「企业智能体」列表中消失；侧栏「助理」入口消失、「助理」「项目」入口位置错乱。
- 5.7.3 优化首页任务推荐加载速度；修复 Windows 从模板创建自动化任务失败、Windows 更新安装期间提前打开应用报错、空间任务列表展开延迟/跳动。

### 3. v5.7.5（10/3）—— 定时任务体系完善 + Outlook 连接器

- **定时任务汇总页**：同一任务历次运行按时间线展示，可集中查看执行结果和产物。
- **定时任务产物系统通知**：点击提醒即可打开对应产物。
- **Outlook 连接器**（海外版）：授权后可处理邮件、日程和联系人。
- 优化：通知提示音默认静音；桌面端**安装包体积减小**；移动端更快收到任务提醒；**图片产物微信分享**（接收方可直接以图片查看）；首次进入对话的等待体验、首页/任务列表加载稳定性。
- 修复 6 项：客户端启动失败/无法登录、长会话历史显示不全、取消任务后丢失上下文、Windows 开机自启失败、断网后消息中心不可用等。

### 4. v5.7.6（10/4，当前最新）

- **Gmail 连接器**（海外版）：授权后可直接读取和发送邮件。
- 修复：图片生成高积分提醒误触发/漏触发；偶现新建本地任务失败；资料库 PPTX 在线预览慢/空白；云助理发消息无回复、历史消息加载慢；**小程序开发产物被自动清理、预览资源无法加载**（上周报道的小程序能力的后续修复）。

## 三、与小铁智友功能差异的初步判断

| WorkBuddy 本周动态 | 小铁智友现状 | 判断 |
|---|---|---|
| 定时任务页面焕新（模板/配置/运行记录集中管理、失败原因定位） | 有自动化任务体系（automation_update 创建/查看/列表），但无面向用户的任务管理 UI（模板、运行历史时间线、失败定位视图） | ⚠️ 部分有 → 需要评估（能力在、呈现层差距明显） |
| 定时任务产物系统通知（点击提醒直达产物） | 自动化执行后只在会话内产出结果，无系统级通知与产物直达 | ❌ 没有 → 需要评估 |
| 全局搜索（资料库 + 聊天记录统一搜索） | 有 conversation_search（历史会话检索），但无本地资料库/文件内容的全局搜索入口 | ⚠️ 部分有 |
| 工作区信任确认（首次打开含开发配置的工作区时确认） | 有权限确认机制，但无「工作区含开发配置 → 主动提示信任」的分级机制 | ⚠️ 部分有 |
| 桌面任务通知 + 关联移动端提醒 | 无移动端，无系统通知推送 | ❌ 没有 |
| 对话内插件查看卸载、技能搜索安装 | 有 SkillManage 与技能市场安装能力 | ✅ 我们有 |
| Markdown 查找替换、预览缩放、HTML 页面内查找 | 有 HTML 产物预览；Markdown 查找替换/预览缩放无专门支持 | ⚠️ 部分有 → 低成本可补 |
| 从 WorkBuddy 在 CodeBuddy 中打开工作空间 | 无对应 IDE 联动 | ❌ 没有（依赖生态，短期难跟进） |
| 开发者分享专家/应用/技能的公开链接 | 专家/技能无分享链接直达机制 | ❌ 没有 |
| Outlook / Gmail 连接器（均为海外版） | 连接器列表有 QQ 邮箱（未连接），无 Outlook/Gmail | ⚠️ 部分有（海外版功能，国内场景优先级低） |
| 安装包体积减小、通知默认静音等体验优化 | 桌面安装包体积是我们已知的分发痛点（大文件下载易失败） | ✅ 方向一致 → 值得对照优化 |
| 小程序产物误清理等修复 | 不涉及（无小程序能力） | — |

## 四、小结与建议

本周 WorkBuddy 的主线非常清晰：**把「定时任务」从附属功能升级为核心功能板块**（5.7.0 页面焕新 → 5.7.5 汇总时间线 + 产物系统通知），同时开始**邮件生态布局**（Outlook + Gmail 连接器，均面向海外版），并持续打磨桌面端基础体验（安装包体积、启动/登录稳定性、长会话性能）。发布节奏维持高频（4 天 3 版）。

值得注意的是：我们的竞品周报本身就是用「自动化定时任务」跑出来的——WorkBuddy 本周恰好重兵投入同一能力方向，说明双方都认定「定时自动化」是 AI 桌面智能体的关键留存场景。

### ⚠️ 建议尽快评估
1. **定时任务管理体系**：竞品已完成「模板 + 运行记录时间线 + 失败定位 + 产物通知」闭环。我们后端能力（automation_update、SQLite 运行历史）已具备，缺的是用户可见的管理界面与系统通知，建议评估补齐呈现层，防止在这条已对标的赛道上体验掉队。
2. **全局搜索（资料库 + 聊天记录）**：用户资产（文件、历史对话）积累后的检索刚需，竞品已做统一入口，建议评估资料库内容索引与搜索方案。
