## 二、本周更新内容摘要

### 1. 微信小程序发布能力上线（9/24，v5.6.1+）⚠️ 重大
- 全栈「应用生成」能力正式支持**微信小程序**：自然语言描述需求 → 生成完整小程序（自带云数据库、微信授权登录/手机号登录、文件存储等云服务）→ 平台内**预览与发布**一站式完成。
- 无需安装微信开发者工具、无需配置 AppID、无需手动上传代码包；发布时扫码绑定自己的小程序账号即可完成代码上传、试用版生成与提交审核，全程无代码。
- 入口：「代码开发」模式 → 选择「小程序」；PC 端升级至 5.6.1 及以上可用。

### 2. 企业版办公套件化升级（9/23）⚠️ 重大
- 腾讯文档、腾讯乐享、腾讯网盘、安全与效能运营平台、腾讯 AI 设计智能体 **Ardot** 首批接入 WorkBuddy 企业版。
- 企业办公能力（文档/知识库/网盘/设计/安全）统一放进同一套体系，WorkBuddy 在套件中承担智能体入口角色；**价格保持不变**，部分产品提供更高版本权益可按需增购。

### 3. v5.6.2（9/21）—— 稳定性版本
- 优化：文档预览窗口（未登录可预览 PPT）、连接器授权与开关（关闭后对话不再残留可用工具）、技能安装/更新检测与闲置提醒（同名技能不再误标已安装）、减少反复确认专家身份的追问。
- 修复 20+ 项 bug，重点方向：定时任务企微通知延迟/漏发与无运行记录反复执行、连接器授权后卡「连接中」/解除后无法重连、超长本地会话翻页、新建任务工作空间选择丢失、会话卡死等。

### 4. v5.6.0（9/19，略早于本周窗口，但影响较大，一并记录）
- 新增：设置「应用管理」（查看/一键撤销第三方应用与 Buddy 应用授权）；会话消息**引用输入**（选中他人消息作为上下文追问）；巴西葡萄牙语/印尼语界面；**恢复自定义 MCP 直接编辑 mcp.json 并即时生效**；闲置能力提醒卡片；Browser Use 兼容 Edge 加载项商店和 QQ 浏览器。
- 修复：频繁自动掉登录态、内置插件 MCP（微信支付、表格助理等）桌面会话连不上、Windows 子代理随机消失、自动化任务卡死不触发等 20+ 项。

## 三、与小铁智友功能差异的初步判断

| WorkBuddy 本周动态 | 小铁智友现状 | 判断 |
|---|---|---|
| 微信小程序一句话生成 + 平台内预览/发布（含云数据库、微信登录、文件存储接入） | 无对应能力。我们有 CloudStudio 静态站点部署，但不支持小程序生成与发布链路 | ❌ 没有 → 需要评估 |
| 企业版办公套件化（腾讯文档/乐享/网盘/Ardot 打包，价格不变） | 无企业版/套件化形态，单机桌面产品 | ❌ 没有 → 需要评估 |
| 「应用管理」统一查看/撤销第三方应用与 Buddy 应用授权 | 有连接器管理（mcp.json + 连接器面板），但无统一的「应用授权」视图与一键撤销 | ⚠️ 部分有 → 可评估补齐授权管理页 |
| 会话消息引用输入（选中消息作为上下文追问） | 无消息引用交互 | ❌ 没有 → 需要评估（实现成本低，对话体验提升明显） |
| 恢复自定义 MCP 直接编辑 mcp.json 并即时生效 | 已有：`~/.crecbuddypro/mcp.json` 手动维护即核心用法 | ✅ 我们有 |
| 多语言界面（巴西葡语、印尼语） | 中文界面 | ❌ 没有（优先级低，看目标市场） |
| 闲置能力提醒卡片（长期未用插件/技能一键关闭） | 无 | ❌ 没有 → 需要评估（有助于性能与用户认知） |
| Browser Use 兼容 Edge 加载项商店 / QQ 浏览器 | 有浏览器自动化能力（agent-browser skill），未见多浏览器兼容性宣传 | ⚠️ 部分有 |
| 定时任务稳定性修复（企微通知、补跑误判、休眠调度） | 我们也有自动化/定时任务体系，同类问题（休眠唤醒后调度、通知可靠性）值得对照自检 | ✅ 我们有 → 建议对照排查 |
| 内置插件 MCP（微信支付、表格助理）稳定性修复 | 我们已内置微信支付 MCP，此前也踩过 MCP 连接稳定性坑，方向一致 | ✅ 我们有 |

## 四、小结与建议

本周是 WorkBuddy 功能推进较活跃的一周：**「小程序从生成到上线」补全了其应用生成的最后一环**，加上企业版套件化（借腾讯生态打包办公全家桶），其「数字员工 + 办公操作系统」的定位进一步坐实，且明显在向企业市场和海外市场（多语言）扩张。

### ⚠️ 建议尽快评估
1. **微信小程序生成/发布能力**：竞品已打通「需求 → 生成 → 云后端 → 上线」全链路。我们是否需要跟进（哪怕先做「生成小程序代码包 + 引导用户本地发布」的降级版本）建议尽快立项评估。
2. **企业版套件化打包策略**：竞品以不变价格捆绑腾讯系办公产品提升企业侧粘性。若我们有面向企业/内部交付的场景，需评估打包形态与生态合作方式。
