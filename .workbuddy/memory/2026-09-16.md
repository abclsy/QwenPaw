## IdP 会话 cookie 持久化（harvest/restore，14:07 端到端测试 PASS）
- 根因定论：IdP SESSION 是**会话级 cookie**（无 Expires），WKWebView 只存内存，重启即失；小铁智友 localStorage 静默登录不经过 IdP → 永远没有 IdP 会话 → 每次开知识库都被拦扫码页。
- 方案：登录后从 `WKWebsiteDataStore.defaultDataStore().httpCookieStore()` 全量快照存 JSON（`~/.crecpaw_webview_data/idp_cookies.json`），启动/开知识库窗口前注回。新模块 `src/qwenpaw/cli/idp_cookies.py`。
- **pywebview 6.2.1 cocoa 源码关键结论**（解了上轮 probe 失败之谜）：
  - `webview.start(func)` 的 func 线程在 `guilib.create_window(windows[0])` **之前**启动 → func 里立即读 `BrowserView.instances` 必为 0。正确姿势：不碰 instances，直接用 `WebKit.WKWebsiteDataStore.defaultDataStore()` 类方法（所有窗口共享，与窗口创建时机无关）。
  - `getAllCookies_` 回调需主线程 + runloop 运行中：`AppHelper.callAfter`（PyObjCTools）调度 + `threading.Semaphore` 等待 —— pywebview 自己的 `get_cookies()` 就是这么写的，直接抄姿势。
  - pywebview 内置 `Window.get_cookies()` 有个坑：按**当前页面域名**过滤（`domain not in self.url`），拿不到跨域 IdP cookie → 必须绕过它自己 snapshot 全量。
  - 事件回调线程安全：`loaded`/`closed` 事件 `should_lock=False` → 回调在独立线程执行，里面可以安全阻塞等 `callAfter` 回调（不会死锁主线程）；`closing`/`before_show` 是锁内执行（`should_lock=True`），不可阻塞。
- **NSHTTPCookie 重建坑（核心踩坑）**：
  - `NSHTTPCookieHTTPOnly` 属性常量**不存在**（AttributeError），`cookieWithProperties_` 无法表达 HttpOnly → 弃用。
  - 正确姿势：`NSHTTPCookie.cookiesWithResponseHeaderFields_forURL_` 合成 Set-Cookie 头，HttpOnly/Secure/Expires 全保留。
  - **probe 出的规则**：`Secure` cookie 用 `http://` URL 合成会被静默拒绝（返回空数组）→ 一律用 `https://` URL；host-only cookie 不带 Domain 属性（忠实还原 SESSION 的 host-only 语义）；带点 `Domain=.x` 合成 domain cookie；IP host 正常。
  - 过期时间用 `email.utils.formatdate(ts, usegmt=True)` 的 RFC1123 格式塞进 Expires。
- 端到端测试（`/tmp/idp_cookie_test/test_harvest_restore.py`，本地 http server 种 HttpOnly SESSION）：harvest 1 → clear_cookies 全清 → restore 1 → 新窗口真实请求带上 `SESSION=abc123xyz` → re-harvest 可见 → **PASS**。
- desktop_cmd.py 集成（5 个点）：①`_open_main_window_after_ready`：主窗口创建**前** restore（splash runloop 已在跑，callAfter 可用），`main_window.events.loaded` 回调里首 harvest + 启动 60s 保鲜 poller；②`open_knowledge_base`：开窗**前**先 harvest（把 store 最新值刷进备份，防旧备份覆盖新值）再 restore(domains=['tyrz.crec.cn'])，`kb_window.events.closed` 回调再 harvest；③`clear_sso_cookies` 登出时 `delete_backup()` 防 poller 复活刚删的会话。
