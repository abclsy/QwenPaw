# 安全质量硬知识库

## 一、法规体系（引用必须准确到条款）

| 层级 | 核心文件 | 关键条款 |
|------|----------|----------|
| 法律 | 《安全生产法》(2021修正) | 三管三必须（第4条：管行业必须管安全…）；全员安全生产责任制 |
| 法律 | 《建设工程质量管理条例》(国务院令279号) | 质量责任主体：建设/勘察/设计/施工/监理五方 |
| 行政法规 | 《建设工程安全生产管理条例》(国务院令393号) | 危大工程专项方案（第26条） |
| 部门规章 | 《危险性较大的分部分项工程安全管理规定》(住建部令37号，2018) | 危大工程清单+专项施工方案 |
| 铁路 | 《铁路建设工程质量安全监督管理办法》 | 铁路项目适用 |

⚠️ 引用前先确认现行有效版本（修订频繁）；不确定就说"以现行有效版本为准，建议核对"。

## 二、危大工程（专项方案+论证）

**需要专家论证的**（超过一定规模，住建部令37号配套文件清单）：
- 深基坑：开挖深度 ≥5m，或 ≥3m 且地质/环境复杂
- 模板支撑：搭设高度 ≥8m / 跨度 ≥18m / 施工总荷载 ≥15kN/m²
- 起重吊装：单件 ≥100kN；起重机安装拆卸
- 脚手架：搭设高度 ≥50m 落地式钢管
- 暗挖、顶管、人工挖孔桩、拆除、爆破等

**流程**：专项施工方案（施工单位技术负责人审核签字+总监审查）→ 超规模的组织**专家论证**（≥5名专家，方案修改后实施）→ 交底 → 实施 → 验收。

## 三、事故报告（时限是红线）

《生产安全事故报告和调查处理条例》（国务院令493号）：
- 事故发生后**立即**报告单位负责人；负责人接报后 **1小时内**报告县级以上应急管理部门和行业主管部门
- 铁路工程同时按国铁集团事故报告制度执行
- **迟报、漏报、谎报、瞒报**：对单位处罚 + 对负责人处分（安全生产法第107条）
- "四不放过"：原因未查清不放过 / 责任人未处理不放过 / 整改措施未落实不放过 / 有关人员未受教育不放过

## 四、铁路工程质量验收层级

检验批 → 分项工程 → 分部工程 → 单位工程，逐级验收：
- 检验批：主控项目 100% 合格，一般项目达到规范比例
- 隐蔽工程：**验收合格才能覆盖**（留存影像+记录）
- 常用规范：《铁路混凝土工程施工质量验收标准》、《铁路路基工程施工质量验收标准》等（TB 10424 系列等，以现行版本为准）

## 五、隐患排查工作流

1. **排查清单**：按工序/部位建立（基坑、高支模、起重吊装、临时用电、隧道超前支护…）
2. **定级**：一般隐患（立即整改）/ 重大隐患（停工整改+专项方案+验收销号）
3. **闭环五步**：排查登记 → 下发整改通知 → 整改回复 → 复查验证 → 销号归档
4. 铁路项目另有"红线管理"条款（触碰即停工整顿，如隧道衬砌厚度不足、无砟轨道精度超限等，以建设单位红线文件为准）

## 六、工作方法

- 用户报"出事了"：第一响应是**救人→报告（1小时红线）→保护现场**，然后才是分析
- 方案审查四查：依据是否现行 / 程序是否完备（论证、审批、交底签字）/ 措施是否针对性 / 应急预案是否可执行
- 拒绝协助规避安全监管、篡改检查记录、应付检查的"纸面整改"——明确拒绝并给出合规做法
- 出具的风险提示要写明：风险源 / 可能后果 / 规范依据 / 整改建议 / 复查标准
