# 建设工程法律硬知识库

## 一、法律体系速查（效力层级从高到低）

1. **民法典**：第三编合同（第788条起建设工程合同章）+ 第799条竣工验收
2. **法律**：建筑法、招标投标法、安全生产法
3. **行政法规**：建设工程质量管理条例（279号）、安全生产管理条例（393号）、招标投标法实施条例
4. **司法解释**：《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》（法释〔2020〕25号）——**工程纠纷的实操核心**
5. 部门规章/地方规定/通用合同条款（GF-2017-0201）

## 二、司法解释（一）高频条款（必须准确）

| 情形 | 规则 |
|------|------|
| 无效合同（无资质/借用资质/必须招标未招标） | 参照合同结算折价补偿（24条） |
| 无效合同工程质量合格 | 承包人可请求参照合同支付（24条） |
| 实际施工人 | 可向发包人主张，发包人在欠付范围内担责（43条） |
| 竣工日期 | 验收合格之日；未验收先使用的，以转移占有之日（9条） |
| 结算依据 | 有约定从约定；以审计结论为准需明确约定，否则不当然约束双方 |
| 质量保证金返还 | 按约定缺陷责任期，最长不超过 2 年（17条） |

## 三、诉讼时效与除斥期间（错过=失权）

- 普通诉讼时效 **3 年**（民法典188条），从知道或应当知道权利受损起算
- 工程款结算时效起算：结算完成日/约定付款日（有争议时尽早主张或发函中断时效）
- **中断事由**：催款函（留送达证据）、部分履行、起诉/仲裁——每次中断重新起算 3 年
- 撤销权（欺诈/显失公平）：1 年除斥期间（民法典152条）
- 建设工程价款**优先受偿权**：应当在合理期限内行使，最长不超过 18 个月（自发包人应给付款之日起，民法典807条+司法解释36条）

## 四、纠纷处理路径

```
协商 → （监理/造价咨询调解）→ 仲裁 或 诉讼
```
- 仲裁 vs 诉讼：看合同争议条款（或裁或审，选一不可逆）；仲裁一裁终局、保密、快
- 证据链组织五类：合同及补充协议 / 履约记录（签证、纪要、往来函）/ 影像与日志 / 结算与财务凭证 / 鉴定意见
- 造价鉴定：举证责任在主张方；鉴定范围争议要及时提书面异议（不提视为认）

## 五、合规审查要点（央企语境）

- **三重一大**：重大决策、重要人事、重大项目、大额资金——集体决策留痕
- 招标红线：化整为零规避招标、明招暗定、评标后实质性谈判（招标投标法43/46条）
- 分包合规：主体结构不得分包；违法分包/转包认定（司法解释1条）→ 合同无效+行政处罚
- 廉洁条款：央企与分供商合同标配；商业贿赂零容忍

## 六、工作方法

- 每个结论三段式：事实定性 → 法条（准确到条/款/司法解释）→ 处理建议
- 时效类问题先算时间线再谈方案；已过时效的如实告知并给补救思路（自愿履行不受时效限制）
- 提示重大事项走正式程序：诉讼/仲裁方案、和解协议必须经公司法务审核，AI 输出仅供内部研讨
