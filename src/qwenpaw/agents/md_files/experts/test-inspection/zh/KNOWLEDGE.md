# 试验检测硬知识库

## 一、核心规范族（以现行有效版本为准）

- 《铁路混凝土工程施工质量验收标准》系列（TB 10424 等）
- 《混凝土物理力学性能试验方法标准》GB/T 50081
- 《普通混凝土配合比设计规程》JGJ 55
- 《建筑地基基础工程施工质量验收标准》GB 50202
- 铁路项目另执行《铁路工程试验检测管理办法》及建设单位试验检测细则

## 二、取样频率高频数字（必须记牢）

| 项目 | 频率 |
|------|------|
| 水泥（同厂同品种同强度等级同批号） | 散装 ≤500t/批，袋装 ≤200t/批 |
| 钢筋原材 | 同炉批号 ≤60t/批（冷拉等另有规定） |
| 钢筋焊接/机械连接接头 | 每 300 个接头为一批（外观+力学） |
| 砂/碎石 | 同料源同规格 ≤600t（或400m³）/批 |
| 砼坍落度 | 每工作班不少于 1 次（泵送/高温加密） |
| 砼强度试件 | 同配合比每 100盘且不超过 100m³ 取样不少于一次；每工作班至少一次 |
| 大体积砼测温 | 覆盖养护期全程，内外温差 ≤25℃（GB 50496） |

⚠️ 见证取样：按建设部规定比例（≥30%）由监理见证，记录签字闭环。

## 三、配合比设计流程（JGJ 55）

1. 配制强度：fcu,0 = fcu,k + 1.645σ（σ 按历史统计或规范取值）
2. 水胶比：W/B = αa·fb/(fcu,0+αa·αb·fb)（碎石/卵石系数不同）
3. 用水量（查表+坍落度调整）→ 胶材用量 = 用水量/水胶比
4. 砂率（查表）→ 粗细骨料（质量法或体积法）
5. 试配调整：三个水胶比（基准±0.05）→ 强度-灰水比线性关系 → 确定实验室配合比
- 耐久性校核：铁路砼还有电通量/抗渗/抗冻等指标要求（TB 10005 环境类别）

## 四、实体检测高频项

- **回弹法**（JGJ/T 23）：碳化深度修正；只能推定，不替代标养试块
- **钻芯法**（JGJ/T 384）：强度仲裁；芯样 φ100 修正
- **钢筋保护层**（JGJ/T 152）：梁类允许偏差 +10/-7mm，合格点率 ≥90%
- **桩基检测**：低应变（完整性 Ⅰ~Ⅳ 类判定）+ 承载力（静载/高应变，抽检比例按规范与设计）
- **隧道衬砌**：地质雷达（厚度+背后空洞），第三方检测必查

## 五、不合格处理决策树

```
原材料不合格 → 双倍复检（仍不合格→退场，追溯已用部位）
砼试块不合格 → 回弹→芯样验证（仍不合格→实体强度评定+设计验算→加固/返工方案）
桩 Ⅲ 类桩 → 补勘+设计复核处理方案；Ⅳ 类桩 → 补桩或加固，必须设计出方案
```

**数据红线**：检测数据不得修改、不得补录；台账与报告编号一一对应，可追溯。

## 六、工作方法

- 给结论必带规范号+条款位置；数字（频率/限值）记不准时明确说"需查表"，不背错数
- 报告审核三对：报告数据↔原始记录↔台账，编号连续、日期逻辑合理
- 涉及结构安全判定的（砼强度不足、桩缺陷），只做技术分析，处理方案由设计单位出
