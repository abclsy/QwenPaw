# 施工组织硬知识库

## 一、施工组织设计层级

| 层级 | 编制者 | 审批 |
|------|--------|------|
| 指导性施组（投标/开工前） | 施工单位 | 建设单位/监理审批 |
| 实施性施组（项目级） | 项目部 | 企业技术负责人审批+监理 |
| 专项方案（单位/分部工程） | 项目部 | 按危大工程管理规定执行 |

修改原则：重大调整（工期、方案、大临）重新审批；一般调整留版痕记录。

## 二、进度计划方法选择

- **横道图（甘特图）**：管理层汇报、逻辑简单项目
- **双代号/单代号网络计划**：需找关键线路、工期优化时——**关键线路 = 总时差为零的线路**，压缩工期只能压关键工作
- 工期优化优先序：①压关键工作（赶工费率最低者先）②调整逻辑关系（流水/平行）③资源二次配置
- **计划值维护**：总工期合同锁死，月度计划对总计划做"前锋线"对比，偏差>10% 必须纠偏

## 三、流水施工参数（速算）

- 流水节拍 t、流水步距 K（等节奏 K=t）
- 工期估算：T = ΣK + Σt_last + Σ间歇（等节奏：T=(m+n-1)×t + Σz）
- 成倍节拍流水：加快的队伍数 = 节拍/流水步距 取整

## 四、大临与平面布置原则

1. 运输线路最短（料场/拌合站靠近控制性工程，利用既有道路）
2. 预制场/拌合站经济半径：拌合站一般 ≤15km（砼罐车 45min 内到现场，依季节调整）
3. 危险品库房与生活区距离满足消防规范，炸药库按民用爆炸物品管理单独审批
4. 临时用地：能租不征、能复垦则复垦；高压线/河道管理范围内禁设大临
5. 隧道口布置：超前于洞口工程完成（风机、变电、排水、弃渣场协议先行）

## 五、资源配置经验值（校核用）

- 人员：按工序高峰系数 1.2~1.3 配置；高峰月避开冬雨季交叉
- 主机设备：利用率 65~75% 为健康区间，>85% 说明无备用、风险大
- 拌合站产能 = 高峰日砼量 × 1.3 安全系数，校核运输罐车数量（每车循环时间法）

## 六、工作方法

- 用户问"工期怎么压"：先画关键线路再谈方案，禁止无网络计划的拍脑袋压缩
- 施组审查四查：方案可行性（对照设计文件）/ 资源可获取性（当地料源/运力）/ 季节适应（冬雨季安排）/ 安全冗余
- 涉及赶工费用：提醒走变更/索赔程序，赶工指令要书面化
- 进度偏差分析给三件套：偏差量、原因归类（业主/设计/施工/不可抗力）、纠偏措施+责任矩阵
