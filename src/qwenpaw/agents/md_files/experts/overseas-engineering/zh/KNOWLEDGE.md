# 国际工程硬知识库

## 一、FIDIC 合同族速查

| 版本 | 适用 | 特点 |
|------|------|------|
| 红皮书（施工合同条件） | 业主设计的施工 | 最常用，单价合同 |
| 黄皮书（生产设备与设计-施工） | 承包商设计施工 | 设计+施工一揽子 |
| 银皮书（EPC/交钥匙） | 业主给总价、承包商担大风险 | ⚠️"业主需求"出错也常归承包商 |
| 绿皮书/白皮书/金皮书 | 短合同/DAB/设计 | 按需选用 |

**FIDIC 1999/2017 版关键时限（红皮书惯例）**：
- 索赔：察觉或应察觉后 **28 天**内发索赔通知（2017 版 20.2.1），失效即失权
- 争议：DAB/DAAB 裁决 → 28 天内发不满意通知 → 仲裁（ICC/机构仲裁）
- 2017 版新增：提前预警、青年工程师条款；索赔与争议分两条线（20条索赔/21条争议）

## 二、合同价格与货币风险

- 价格类型：总价（银皮书）/单价（红皮书）/成本加酬金（紧急救灾重建）
- **货币错配**：收入币种 vs 成本币种 vs 报表币种，三张皮最危险
- 汇率对冲工具：远期结售汇 / 货币互换 / 当地币及时结汇（贬值通道里不留当地币余额）
- 报价原则：主币种=贷款币种或硬通货；当地币部分≤30%为宜（视项目而定）

## 三、属地合规（一条不合规则一票否决）

1. **准入**：公司注册/分支机构/代表处三级，各国外资准入目录差异大
2. **税务**：常设机构（PE）认定→所得税；增值税/预扣税（Withholding）谈判税负分担；避免双重征税协定（DTT）利用
3. **劳工**：属地雇佣配额（部分非洲/中东国家要求当地员工比例）、工作签与劳务许可、劳工法解雇成本
4. **海关**：临时进口（设备复出口退税）vs 永久进口；免税函（EPC 合同谈判要点）
5. **反腐败**：FCPA（美国）/ UK Bribery Act（英国）域外管辖——第三方代理是高危区，尽调留痕

## 四、海外投标报价要点

- 调价公式：Pn = P0 × (a + b×En/E0 + c×Ln/L0 + …)，权重 a+b+c=1，谈判争"当地币指数占比"
- 预付款保函/履约保函：融资行担保格式提前锁定（改格式=改费用）
- EPC 报价三陷阱：业主需求模糊（摆明求偿基础）/ 现场条件风险（是否给"不可预见的物质条件"）/ 最低性能保证值（担保值=违约金触发线）
- 报价货币+支付节点+保函费用+税务成本一起算，缺一项就亏

## 五、风险台账（必答题清单）

政治风险（制裁/汇兑限制/政权更迭）/ 商业风险（业主支付能力、主权担保）/ 执行风险（当地供应链、雨季、宗教假期）/ 安全风险（治安、恐怖主义险别）→ 应对：中信保（短期/中长期出口信用险）、政治风险险（MIGA/私营）、合同退出条款。

## 六、工作方法

- 合同问题先定位"哪个红黄银皮书+哪一年版"，条款号差异大，不确认版本不给条款结论
- 汇率/制裁/国别政策时效性极强，标注查询日期与"以现行为准"
- 涉及仲裁、制裁应对：给思路框架，正式方案必须外部律师/合规部出
- 报价测算全程列公式，币种后缀必须写（USD/当地币），混写=重大失误
