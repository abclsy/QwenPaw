# 桥隧硬知识库

## 一、隧道施工核心方法选择

| 围岩级别 | 推荐工法 | 关键措施 |
|----------|----------|----------|
| Ⅰ~Ⅱ级 | 全断面法 | 光面爆破 |
| Ⅲ级 | 全断面/台阶法 | 及时初期支护 |
| Ⅳ级 | 台阶法/CD/CRD | 超前支护（小导管/管棚）、锁脚锚杆 |
| Ⅴ~Ⅵ级 | CRD/双侧壁导坑 | 超前大管棚+注浆、步步成环 |

**铁律**：软弱围岩"短进尺、弱爆破、强支护、早封闭、勤量测"十八字方针；仰拱与二衬距掌子面距离必须满足规范（铁路：Ⅳ级围岩≤35m/Ⅴ级及以上≤28m，以现行标准为准）。

## 二、监控量测必测项目（铁路隧道）

拱顶下沉、水平收敛、地表沉降（浅埋段必测）。频率：开挖后 1~15 天 1~2 次/天 → 16~30 天 1 次/2天 → 之后降低。**量测数据异常（速率突增）= 立即停工预警**。

## 三、桥梁常用结构形式与适用

- **简支T梁/箱梁**：32m 标准跨度预制架设为主（铁路标准跨）
- **连续梁**：悬浇（挂篮）常用 48+80+48 等跨度组合；合龙顺序先边跨后中跨
- **连续刚构/拱/斜拉**：大跨度，施工监控是关键（线形+应力双控）
- 预应力：张拉"双控"（张拉力+伸长量，偏差 ±6%）；压浆饱满度是质量通病高发区

## 四、质量通病库（高频问题速查）

1. **衬砌背后空洞** → 带模注浆/雷达检测（第三方检测必查项）
2. **二衬厚度不足/强度不足** → 红线问题，凿除重做
3. **隧道渗漏水** → 防水板焊接质量 + 施工缝止水带安装
4. **桥头跳车** → 台背回填（压实度≥96%）+ 桥台过渡段
5. **预应力压浆不密实** → 孔道检测 + 真空辅助压浆
6. **梁体裂缝** → 分类型判读（收缩裂缝 vs 受力裂缝，后者需评估处理）

## 五、工作方法

- 方案比选给"技术+经济+工期+风险"四维对比，不只讲技术
- 涉及规范的结论（限值、距离、强度等级）注明标准号；记不准就标注"需查现行版本"
- 重大方案（改变支护参数、跨度调整）提醒走设计变更程序，不替设计单位做决定
- 施工事故先因分析：按"人机料法环"逐项排查，给出证据链而非猜测
