# 投资开发硬知识库

## 一、主流投融资模式对比

| 模式 | 适用 | 关键点 |
|------|------|--------|
| PPP（新机制） | 有经营性现金流的公共项目 | 聚焦使用者付费；特许经营新办法（2024年17号令）后**优先民企参与** |
| 特许经营 | 高速/供水等 | 运营期承担风险，政府不给固定回报承诺 |
| EPC+F / F+EPC | 政府项目垫资 | ⚠️ 央企被严控新增；隐性债务红线 |
| 片区开发（ABO+/投资人+EPC） | 综合开发 | 产业导入是根本；防新增隐性债（财政部问责通报高频区） |
| 城市更新 | 旧改 | 一二级联动看地方政策；村民/产权方谈判是关键路径 |

**铁律**：任何模式先过"隐性债务"审查——政府兜底、保底收益、回购承诺 = 红线（国办函〔2023〕115 号等现行文件）。

## 二、投资决策流程（央企典型）

项目初判（机会研究）→ 内部立项 → 尽调（法律/财务/工程三线）→ 可研与测算 → 投委会决策 →（PPP/特许经营走法定程序）→ 签约 → 融资交割 → 实施 → 后评价
- 尽调红线：土地权属瑕疵、已抵押资产、未决诉讼、环评/规划不符——一项硬伤即可否决
- 决策文件要件：可研+测算模型+风险评估+合规审查意见，缺一上不了会

## 三、经济测算核心指标

- **NPV（净现值）**：≥0 可行；折现率取行业基准收益率或 WACC
- **IRR（内部收益率）**：与折现率比较；央企一般要求全投资 IRR ≥ 基准（各集团口径不同，6%~8% 常见）
- **资本金比例**：城市基建类项目资本金 ≥20%（现行固定资产投资资本金制度，行业有别）
- **回收期**：静态/动态，特许经营类项目回收期应明显短于特许期
- 敏感性分析必做：收入 ±10%/±20%、投资 ±10%、工期延误 6 个月，三因素各算一遍

## 四、片区开发实操要点

1. **交易结构**：合作范围（土地一级/基建/产业/运营）拆分清晰，回报机制一一对应
2. **回报来源合规**：土地出让收入挂钩 → 高风险；争取专项债/专项资金/使用者付费组合
3. **政企风险分配**：征拆交给政府、融资给社会资本、不可抗力共担——写进协议才有效
4. **退出机制**：股权回购、REITs（基建公募 REITs 是当前退出主通道）、资产证券化
5. **产业逻辑先行**：没有产业导入承诺与考核的开发项目=伪需求，测算再好看也过不了会

## 五、工作方法

- 测算问题先核"三口径"：资金来源（资本金/债）、时间口径（建设期/运营期）、税（含税/不含税），口径错则全盘错
- 模式建议必须带"隐性债务合规审查"结论，灰色结构如实标注风险等级
- 给决策材料列"要件清单"（缺什么材料不能上会），比替用户拍结论更有价值
- 政策时效性极强（PPP 新机制、专项债投向年年调整），所有结论标注"以现行文件为准"
