# 党建宣传硬知识库

## 一、材料类型与文风要求（一文一格）

| 文体 | 核心结构 | 大忌 |
|------|----------|------|
| 工作总结 | 总述（成绩定调）→ 分块成效（数据+案例）→ 存在问题 → 下步打算 | 只报流水账 |
| 汇报材料 | 上级视角：落实了什么要求→怎么做→效果→下一步 | 自说自话不扣上级精神 |
| 新闻稿 | 倒金字塔：导语（何人何事何果）→ 细节 → 意义/展望 | 前三行抓不住人 |
| 经验交流 | 亮点提炼（一二三级标题出观点）→ 做法 → 启示 | 标题无观点 |
| 先进事迹 | 故事化：场景细节+人物语言+精神提炼 | 高大全没人信 |

## 二、党建材料核心规范

- **标题句式**：动宾结构出观点（"三抓三促"式、对仗式），忌"关于…的工作情况"平铺
- **数据呈现**：党建成效数字化（学习覆盖率、党员攻关项目数、创效金额）——党建与生产经营深度融合是硬要求
- **术语准确**：党内称呼规范（同志）、机构名全称首现后简称、"三会一课"（支部党员大会/支委会/党小组会+党课）、"第一议题"制度、主题教育表述以最新党内文件为准
- **敏感表述**：涉党涉领袖引文必须核对原文（出处可查）；政策表述以正式文件为准，不凭印象转述

## 三、央企宣传纪律（红线清单）

1. 未经审批不得接受媒体采访、不得对外发布项目信息（保密+商密双重审查）
2. 重大节点宣传口径与上级保持一致；突发事件"黄金 4 小时"内先报后发
3. 涉军涉警涉敏感工程不宣传；照片背景敏感（图纸/坐标/密级文件）不入镜
4. 典型人物宣传需本人同意+组织审核；涉及安全事故事件的报道须经安全部门会签

## 四、好稿件的五个抓手

1. **小切口**：从一个人/一个凌晨/一张照片切入，不从"今年以来"切入
2. **现场感**：引用当事人原话（带语气词的）、具体时间地点数字
3. **矛盾结构**：困难（雨季/工期/技术卡点）→ 应对 → 转折，没有冲突就没有故事
4. **政治站位**：把项目故事挂到国家战略（一带一路/新基建/交通强国）上收尾
5. **金句收束**：结尾一句提炼（可用于转发文案），不写"下一步将继续"

## 五、工作方法

- 接需求先问四件事：给谁看（上级/公众/内部）→ 发哪里（官网/公众号/内刊）→ 字数时限 → 有没有素材（照片/数据/人物联系方式）
- 初稿给"标题+导语"两个版本供选；改稿保留痕迹稿便于对比
- 引用党建术语没把握的（最新表述/会议全称），明确标注"请以正式文件核准"，不编
- 所有对外发布稿提醒走"三审三校"程序（撰稿人→部门负责人→分管领导）
